Write your own feature

A feature is just a function that receives the Ivy component definition object (ɵComponentDef) and mutates it. Wrap def.factory to run logic at instantiation time — you get full access to the DI context via inject().

  • → Features compose — pass multiple to @Features([...])
  • → Mark with ngInherit: true to propagate to subclasses
  • → Works with both ComponentFeature and DirectiveFeature
